# Shiv Rudraksh Resort - TanStack Start App

## Project Overview
A luxury resort landing page for **Shiv Rudraksh**, a premium riverside retreat in Varanasi, India. The site showcases rooms, spiritual experiences (Ganga Aarti), and fine dining with a cinematic, luxury-focused UI.

## Tech Stack
- **Framework**: TanStack Start (full-stack React framework with SSR)
- **Frontend**: React 19
- **Styling**: Tailwind CSS 4.0
- **UI Components**: Radix UI + Shadcn UI patterns
- **Routing**: TanStack Router (file-based)
- **Data Fetching**: TanStack Query v5
- **Build Tool**: Vite 7
- **Package Manager**: npm (Node 20)

## Project Structure
- `src/routes/` — File-based routing (TanStack Router)
- `src/components/` — UI components (ui/ for primitives, others for features)
- `src/assets/` — Images and static assets
- `src/styles.css` — Global styles
- `src/server.ts` — SSR entry point
- `src/start.ts` — Client hydration entry

## Dev Setup
- Runs on port 5000 (`npm run dev`)
- Vite configured with `host: "0.0.0.0"` and `allowedHosts: true` for Replit proxy

## User Preferences
- Maintain the existing TanStack Start / file-based routing structure
- Keep the luxury, cinematic aesthetic for the resort theme
